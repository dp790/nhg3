日本語 SRS — Kurulum Rehberi
Vercel ile Deploy (Ücretsiz, 5 dakika)
1. Hesap Aç
https://vercel.com adresine git.
"Sign Up" → GitHub veya e-posta ile ücretsiz hesap oluştur
2. Projeyi Yükle — 2 Yöntem
Yöntem A: Sürükle-Bırak (En kolay)
vercel.com'da giriş yap
Dashboard'da "Add New → Project" tıkla
"Or deploy from your local project" seçeneğini bul
Bu klasörü (nihongo-srs) sürükle-bırak yap
"Deploy" tıkla → 1-2 dakikada hazır!
Yöntem B: GitHub üzerinden (Önerilen — otomatik güncelleme)
github.com'da ücretsiz hesap aç
"New repository" → nihongo-srs adıyla oluştur
Bu klasördeki dosyaları upload et (Add file → Upload files)
vercel.com'da "Import Git Repository" → GitHub'ı bağla → nihongo-srs seç
Deploy!
3. Telefona Kur (PWA)
Deploy sonrası sana bir URL verilir (örn: nihongo-srs-abc.vercel.app)

iPhone:

Safari'de URL'yi aç
Alttaki paylaş butonuna bas (kare + ok ikonu)
"Ana Ekrana Ekle" → "Ekle"
Artık uygulama gibi ikonla açılır!
Android:

Chrome'da URL'yi aç
Sağ üstteki 3 nokta menüsüne bas
"Ana ekrana ekle" → "Ekle"
Lokal Çalıştırma (Bilgisayarda)
npm install
npm run dev
Tarayıcıda http://localhost:5173 adresi açılır.
